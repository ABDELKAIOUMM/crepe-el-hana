## 🚀 التشغيل

الموقع ثابت (Static) — أي استضافة ملفات هتشتغل. للنشر على GitHub Pages:

```bash
git push origin main
```

ثم من **Settings → Pages** اختار Source: `main` / root.

> ⚠️ مهم: لو الموقع في مجلد فرعي (مثال `https://user.github.io/crepe-el-hana/`)

## 🎛️ لوحة التحكم

افتح `admin.html` — كلمة السر: **`hana2026`**

بتقدر من غير ما تلمس كود:
- تغيّر **الأسعار** (والبيتزا ليها 3 أحجام: صغير/وسط/كبير)
- تضيف/تعدّل/تحذف **أصناف وأقسام**
- تعدّل **المقاسات والإضافات** وبيانات المطعم
- تغيّر **الصور** (اختيار من الموجود + رفع صورة جديدة)
- تكبّر/تصغّر **7 عناصر نصوص** من غير ما تكسر التصميم
- تعدّل **35 نص** في الموقع

التعديلات بتتحفظ في `localStorage` في متصفحك، وبتظهر **مباشرة** على الموقع.
استخدم زرار **تصدير** عشان تاخد نسخة احتياطية.
